# Datos del proyecto

- `raw/`: los cinco conjuntos descargados de datos.gov.co por `00_Extraccion_datos_gov.ipynb`, con su fecha de descarga y hash SHA-256 en `metadatos.json`. No se editan a mano.
- `homologacion/`: reglas escritas por el equipo para emparejar productos y motivos entre las dos fuentes de quejas (sección 6.2 del cuaderno).
- `procesados/`: la vista minable que genera el cuaderno principal, con su diccionario de variables y sus metadatos (sección 6.5).
